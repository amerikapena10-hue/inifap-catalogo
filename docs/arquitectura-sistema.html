Arquitectura del sistema

Catálogo de Productos y Servicios — INIFAP, Campo Experimental Valle del Guadiana

El sitio sustituye la versión estática (Google Sites) por una aplicación de tres capas: un frontend que el navegador descarga y ejecuta, un servidor que expone una API REST, y una base de datos relacional donde vive el catálogo real de productos y servicios.
